# Lab Collection Calculator v11.07: Search aliases

These are **search aids**, not an authoritative code translation table. The local test's official Quest code and specimen information must be checked before collecting. Non-exact batch matches require confirmation.

| Example typed by staff | Expected matching area |
|---|---|
| Chem 14, chemistry 14 | CMP / comprehensive metabolic panel |
| Chem 7, chemistry 7 | BMP / basic metabolic panel |
| CBC diff, blood count, hemogram | CBC tests, distinguished by differential type |
| Hgb A1c, HbA1c, glycated hemoglobin | Hemoglobin A1c |
| FT4, FT3, TSH reflex FT4 | Free T4, free T3, reflex thyroid testing |
| TPO Ab, anti-TPO | Thyroid peroxidase antibodies, not TPO thrombopoietin |
| hs-CRP, HsCRP | High-sensitivity CRP, not conventional CRP |
| Sed rate, ESR | Erythrocyte sedimentation rate |
| Protime, PT INR, PTT, aPTT | Coagulation tests, not PT antibody panels |
| D-dimer, Ddimer | D-dimer |
| CK, CPK | Creatine kinase |
| hs-TnI, hs-TnT | High-sensitivity troponin I versus T (distinct assays) |
| NT-proBNP | N-terminal pro-BNP, distinct from BNP |
| HBsAg / HBsAb | Hepatitis B surface antigen / antibody (distinct) |
| Anti-HCV, HCV Ab | Hepatitis C antibody and reflex options |
| HIV 4th gen, HIV Ag/Ab | Fourth-generation HIV screening options |
| UCx, urine cx | Routine urine culture and related choices |
| UA reflex culture | Urinalysis with reflex to culture |
| UACR, microalbumin/creatinine | Random urine albumin with creatinine |
| QFT, Quant Gold | QuantiFERON-TB Gold Plus (verify tube configuration) |
| CT/NG, GC/CT | Combined chlamydia/gonorrhea tests (verify collection site) |
| LFT, hepatic panel | Hepatic function panels |
| Hgb, Hct, Plt | Hemoglobin, hematocrit, platelets |
| ASO titer, DHT, EBV panel | Antistreptolysin O, dihydrotestosterone, EBV panel |

Some abbreviations represent **families**, not a single equivalent test. For example: CBC with versus without differential; urine versus blood hCG; standard versus high-sensitivity CRP; BNP versus NT-proBNP; quantitative versus qualitative HBsAb; troponin I versus T; QuantiFERON one-tube versus four-tube; chlamydia/gonorrhea anatomical collection site. Verify the exact code and test name every time. The calculator will not silently add inexact batch aliases.
