# Quest–LabCorp crosswalk candidate expansion, November 22, 2026

## Current published index coverage

- Quest active indexed tests: **3,313**
- LabCorp active indexed tests: **6,015**
- Active Quest tests with a possible LabCorp candidate, including workbook overrides: **1,085**
- Distinct LabCorp codes referenced by active Quest candidates: **1,047**
- Active Quest tests without a candidate: **2,228**
- Indexed LabCorp codes without an active Quest candidate: **4,968**
- Newly added candidate pairs in this expansion: **45**
- Newly added review-only reference rows: **16**

These counts describe the **calculator's existing active search indexes**, not the complete national catalog of either lab. A *possible cross-lab reference* is a code/name/specimen candidate, **not confirmed clinical equivalence or an interchangeable order**. All proposed matches require directory verification of analytes, test method, reflex logic, acceptable specimen, quantity, transport, and local test availability. Review-only rows must not produce codes automatically.

No changes were made to active test catalogs, collection/container calculations, tube grouping, transport or temperature instructions, exclusion lists, or printouts.
